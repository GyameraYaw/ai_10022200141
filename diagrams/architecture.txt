  │  → election_numeric | budget_policy | general        │
  └──────────────────────────┬───────────────────────────┘
                             │  intent
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  memory.py — Stage 3: Domain Boosts [PART G]         │
  │  • +β to chunks matching intent                      │
  │  • +β×0.5 × numeric/monetary density                 │
  │  • −0.05 penalty on recently-seen chunks             │
  └──────────────────────────┬───────────────────────────┘
                             │  domain_boosts dict
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  retriever.py — Stage 4: Hybrid Retrieval [PART B]   │
  │  • embedder.encode_single(query) → query_vec         │
  │  • vector_store.search() → cosine scores             │
  │  • BM25.scores_for_query() → keyword scores          │
  │  • combined = α×vec + (1-α)×bm25 + domain_boost      │
  │  • Sort descending, take top-k                       │
  └──────────────────────────┬───────────────────────────┘
                             │  list[(Chunk, combined, vec, bm25)]
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  prompt_engine.py — Stage 5: Context Selection [PART C]│
  │  • Filter score < MIN_SCORE                          │
  │  • Truncate each chunk to MAX_CHUNK_CHARS            │
  │  • Budget-fit to MAX_CONTEXT_CHARS                   │
  └──────────────────────────┬───────────────────────────┘
                             │  selected[(Chunk, score)]
                             ▼
  ┌──────────────────────────────────────────────────────┐
  │  prompt_engine.py — Stage 6: Prompt Build [PART C]   │
  │  Template v3 (grounded + citations):                 │
  │  SYSTEM role + rules + numbered context + query      │
  └──────────────────────────┬───────────────────────────┘
